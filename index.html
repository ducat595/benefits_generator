日本株チェック・評価について

日本株の評価では何を確認しますか？

企業の収益性や割安度だけでなく、PER・PBR・ROE、移動平均、RSI、MACD、出来高、信用需給などを組み合わせて確認します。本アプリでは取得できた決算・ニュースや国内外の市場環境も表示します。

今日の動向・大引け予想とは？

当日の値動き、始値・高値・安値、出来高、テクニカル指標、市場全体の動向、取得できた決算・ニュースなどを材料にしたモデル推定です。上昇・下落確率や中心予想価格は参考情報であり、実際の終値を保証するものではありません。

株価予想だけで売買判断できますか？

いいえ。予想には誤差やデータ欠損があり、相場急変も起こります。企業の開示情報やリスクを確認し、複数の情報源と組み合わせて判断してください。

📊 株価の評価方法

株価を評価するときは、1つの指標だけで「買い・売り」を判断するのではなく、割安性・収益性・成長性・財務健全性・株価の勢い・リスクを組み合わせて見ることが重要です。

以下の数値は一般的な参考目安です。業種・企業規模・景気・金利などによって適正水準は異なります。

評価項目見るポイント参考となる考え方・目安
PER株価の割安性利益に対して株価が何倍まで買われているかを確認します。単純に低いほど良いとは限らず、同業他社やその企業の過去のPERと比較するのが基本です。
ROE収益性株主資本を使ってどれだけ利益を生み出しているかを見る指標です。10%以上を一つの参考目安とし、15%以上なら比較的高い収益性と考えられます。ただし業種差があります。
成長率企業の成長性利益成長率を優先し、取得できない場合は売上成長率を参考にします。プラスであることに加え、数年間継続して成長できているかを見ることが重要です。
自己資本比率財務健全性総資産のうち返済不要の自己資本が占める割合です。一般に高いほど財務の安定性が高いと考えられますが、銀行など業種によって適正水準が大きく異なります。
目標株価現在値との比較現在株価より目標株価が高い場合は上昇余地の参考になります。本アプリでは目標株価が現在値より10%以上高ければ「割安」、10%以上低ければ「割高」、その間を「妥当」と表示します。
短期上昇力株価の勢い直近5営業日と約20営業日の値動きを利用した参考スコアです。高いほど最近の上昇モメンタムが強いことを示します。
安定性値動きの安定度直近約1か月の日々の値動きから算出した参考スコアです。高いほど日々の変動が比較的小さいことを示します。
暴落リスク下落への注意直近約3か月の高値からの最大下落幅を参考にします。過去に大きく下落している銘柄ほど、値動きの大きさに注意します。
陽線・陰線直近の売買の勢い終値が始値より高ければ陽線、低ければ陰線です。1日だけで判断せず、株価トレンドと合わせて確認します。

評価するときの6つの視点

  1. 割安性：PERや目標株価を見て、現在の株価が企業価値に対して高すぎないか確認します。
  2. 収益性：ROEなどから、企業が効率よく利益を生み出しているか確認します。
  3. 成長性：利益・売上の成長が続いているか確認します。
  4. 財務健全性：自己資本比率などから、財務面に無理がないか確認します。
  5. 株価モメンタム：短期上昇力や陽線・陰線から、最近の株価の方向を確認します。
  6. リスク：安定性や暴落リスクから、どの程度の値動きを許容する必要があるか確認します。

総合的な見方

例えば、PERが比較的割安、ROEが高い、成長率がプラス、財務が安定し、株価にも上昇傾向がある銘柄は、複数の面から評価しやすい候補になります。一方で、PERだけが低い銘柄には業績悪化などの理由がある場合があり、ROEや成長率だけが高い銘柄も株価がすでに割高になっている場合があります。

そのため、本アプリの「AIおすすめ銘柄」やスコアも最終的な売買判断ではなく、詳しく調べる銘柄を絞り込むための参考情報として利用することをおすすめします。

重要：ここに記載した基準は一般的な参考情報であり、将来の株価上昇や利益を保証するものではありません。企業の決算、業績予想、ニュース、市場環境、金利、為替なども確認し、最終的な投資判断はご自身で行ってください。

❓ 使い方

1. お気に入り

  • 銘柄コードを入力して「コードで追加」を押すと、日本語の会社名を補って登録します。
  • 会社名を入力して「コードで追加」を押すと東証銘柄を検索します。表示された候補の「選択して追加」を押してください。
  • 会社名をクリックすると会社四季報オンライン、コードをクリックすると株価情報ページが開きます。
  • お気に入りは同じブラウザーに保存されます。15件を超える場合はリスト内をスクロールできます。
  • お気に入りを追加・変更すると、最新の一覧をブラウザー内の既定バックアップへ自動保存します。「お気に入り復元」を押すとファイル選択をせず、この既定バックアップを自動で読み込んで復元します。
  • 追加時には機種変更・端末初期化に備えて「日本株チェッカー_お気に入り_YYYYMMDD_HHMMSS.json」も端末へ自動保存します。
  • 機種変更時：ブラウザー内の既定バックアップは新しい端末へ自動では移りません。旧端末で保存された最新のJSONファイルをiCloud Drive、Google Drive、AirDrop、USBなどで新端末へ移して保管してください。現在の「お気に入り復元」ボタンは同じ端末・同じブラウザー内の既定バックアップを復元する機能です。
  • 注意：ブラウザーのサイトデータを完全に削除すると、通常のお気に入りとブラウザー内の既定バックアップの両方が消えます。端末外のJSONバックアップは機種変更・初期化に備えて残してください。

2. 株銘柄詳細評価

  • 「株銘柄詳細評価」では、銘柄コード・日本語名称・英語名称を入力して「検索」を押すと、東証銘柄の候補を検索できます。
  • 検索結果の「詳細評価」を押すと、銘柄コード・日本語名称・業種、現在株価、目標株価、目標株価との差、短期視点・長期視点の参考評価を表示します。
  • 評価カード上部の銘柄コードをクリックすると株価チャート、日本語名称をクリックすると会社四季報オンラインの銘柄個別ページが開きます。
  • 短期視点は直近の値動き、前日比、ローソク足などをもとに「強気・中立・弱気」で表示します。短期の予想レンジは直近約20営業日の値動きから計算した、約5営業日の統計的な参考範囲です。
  • 長期視点は目標株価との乖離、成長率、ROE、自己資本比率、PERなど、取得できた指標をもとに「強気・中立・弱気」で表示します。
  • 強気は赤系、中立は黄系、弱気は青系で色分けします。目標株価など取得できない項目は「—」になります。
  • カード下部の「お気に入り追加」から通常のお気に入りへ登録できます。すでに登録済みの場合は「お気に入り登録済み」と表示します。
  • 短期予想レンジ・長期見通し・目標株価は将来の株価や投資成果を保証するものではなく、銘柄比較のための参考情報です。

3. 一括チェック

  • 「最新データを取得して一括チェック」を押すと、お気に入りの現在値、PTS株価、目標株価、株価水準（割安/妥当/割高）、前日比、陽線/陰線、スコアを取得します。
  • 結果はスコア順です。PTS株価は現在値より高いと緑、低いと赤で表示し、隣にPTS差額（PTS株価−現在値）を表示します。
  • スマートフォンでは横長の表を1銘柄1カード形式に切り替えて表示します。PCでは従来どおり表形式で表示します。
  • 現在値をクリックすると株価チャートが新しいタブで開きます。
  • 一括チェックでは成長率（利益成長率を優先し、未取得時は売上成長率）を表示します。
  • 短期上昇力・安定性は直近の日足変動からの参考スコア、暴落リスクは直近約3か月の最大下落幅です。PER・ROE・自己資本比率・成長率は取得できた財務データを表示します。未取得時は「—」になります。

4. 為替情報

  • 「為替情報」タブで米ドル/円の現在レート、直近約5営業日の動きをもとにした今後の円高・円安方向の参考コメント、為替チャート、関連ニュースを確認できます。
  • チャートは分足・時間足・日足・週足・月足に切り替えられます。各欄の見出しを押すと折りたためます。
  • 見通しコメントは短期推移に基づく参考情報であり、将来の為替レートを予測・保証するものではありません。

5. AIおすすめ銘柄

  • タブを開くと、現在値・目標株価・株価水準（割安/妥当/割高）・陽線/陰線・スコア・おすすめ判定を自動取得します。
  • 一覧に短期上昇力・安定性・暴落リスク・PER・ROE・成長率・自己資本比率を表示します。数値は取得できた最新データに基づく参考情報です。
  • スマートフォンでは銘柄ごとのカード形式、PCでは表形式で表示します。
  • 現在値をクリックすると株価チャートが新しいタブで開きます。
  • 一覧の行にマウスを重ねると、その銘柄の業種を表示します。
  • おすすめはスコア55以上、強くおすすめは75以上です。

6. 値上がり・値下がりランキング

  • スマートフォンではランキングも1銘柄1カード形式、PCでは表形式で表示します。
  • 「値上がり・値下がり」タブを開くと、値上がり率・値下がり率それぞれ上位20社を表示し、お気に入り一括チェックと同じ詳細項目（現在値・PTS株価・PTS差額・目標株価・株価水準・短期上昇力・安定性・暴落リスク・PER・ROE・成長率・自己資本比率・前日比・陽線/陰線・スコア・おすすめ判定）を取得します。
  • 銘柄名をクリックすると会社四季報オンラインの該当銘柄ページが開きます。
  • 現在値をクリックすると株価チャートが新しいタブで開きます。
  • ランキングには取得した市場データの更新時刻が表示されます。リアルタイム配信ではなく、遅延する場合があります。

株主優待データの年度更新（管理者向け）

株主優待データは、年1回または必要な時にPC上の「EDINET 株主優待JSON生成ツール」で作成し、GitHubのstock_appリポジトリにある shareholder_benefits.json を手動で置き換えて更新します。公開アプリからEDINET APIを直接呼び出す方式ではありません。

  1. benefits_generator_app.py と start_benefits_generator.bat を同じフォルダーに置きます。
  2. Windowsで start_benefits_generator.bat をダブルクリックします。ブラウザーでローカル生成画面が開きます。
  3. 対象年度とEDINET APIキーを入力して「生成開始」を押します。APIキーは生成ツールのファイルには保存されません。
  4. 処理完了後、generated_benefits フォルダーに年度別JSON、最新版用 shareholder_benefits.json、要レビューJSON、処理レポートJSONが作成されます。
  5. 要レビューJSONと処理レポートを確認し、公開候補について企業公式IRで制度継続・権利確定日・必要株数・優待内容を確認します。
  6. 確認後の shareholder_benefits.json をGitHubの stock_app/shareholder_benefits.json と手動で置き換えてコミットします。GitHub Pages反映後、株主優待検索で内容を確認します。

注意：EDINETの有価証券報告書には株主優待専用の統一項目がないため、生成ツールは本文から候補を抽出します。「記載が見つからない＝優待なし」とは判定しません。公開前の公式IR確認を必須としてください。また、処理中はPCをスリープさせず、生成画面を閉じないでください。

成長率取得できた利益成長率を優先し、代替取得時には売上成長率などを表示します。取得できた財務データによって内容が異なります。
自己資本比率総資産に占める自己資本の割合です。財務健全性を見る代表的な指標の一つです。
陽線／陰線始値と終値（または取得時点の値）の関係を表します。陽線は上昇、陰線は下落、同値は同時線です。
スコア本アプリ独自の条件を組み合わせた参考スコアです。将来の値上がりや投資成果を保証するものではありません。
おすすめ判定スコア等をもとに「強くおすすめ」「おすすめ」「様子見」「慎重」などを表示します。売買を推奨するものではなく、銘柄比較のための参考表示です。

※ 外部サイトへのリンクは新しいタブで開きます。外部サイトの表示内容・提供条件は各サービスに準じます。

8. 株主優待検索

  • 「株主優待検索」で1月から12月の権利確定月を選び「リスト表示」を押すと、対象銘柄を優待権利確定日順に表示します。
  • PCでは表形式、スマートフォンでは読みやすい1社1カード形式で表示します。
  • 会社名は会社四季報オンライン、現在株価は株価チャートへリンクします。
  • 右端の「お気に入り追加」から銘柄をお気に入りへ登録できます。
  • 優待制度は変更・廃止される場合があります。権利取得前に企業公式IRで最新条件を確認してください。

9. 起動とデータ取得

  • GitHub Pages版では株価・PTS・全銘柄検索の取得にオンラインAPIを使います。初回やしばらく利用がなかった後は、データ表示まで1分ほどかかることがあります。
  • ローカル版を使う場合は、同じフォルダーにある「stock_checker_start.bat」を起動し、表示されたアドレスをブラウザーで開いてください。終了するときはコンソールで Ctrl+C を押します。
  • 株価データは取得時点の市場データを使用します。PTS価格は夜間PTS情報がある場合に表示され、データがない場合は「—」になります。
  • 株価水準は現在値と目標株価を比較し、目標株価が10%以上高ければ「割安」、10%以上低ければ「割高」、その間は「妥当」と表示します。目標株価がない場合は判定できません。
